## Prompt

去掉固定的 L / G / P / R 业务线和项目化规则，将仓库收缩为可分享的多 Agent Markdown 协作协议与最小网页投影；Agent 可按任务需要自行定义任意 stream。

## 计划

- 将任务协议缩成 `id/title/status/created` 四个必填事实，加上自由文本 `owner/stream/due`；活动任务和归档任务分别放在两个扁平目录。
- 重写 CLI、检查器和本地网页服务，删除固定线、阶段、轨道、标签、拖动排序及网页写操作，只保留创建、读取、完成待审、打回、归档和自动刷新。
- 重写 README、AGENTS、CLAUDE 与任务协议说明，突出唯一事实、显式所有权、追加式交付、自由分流和网页只读投影五个第一性原理。
- 迁移现有 Task MD，运行完整生命周期与 HTTP 冒烟，检查仓库残留概念后提交并推送。

## 进展

- 已确认工作树在本轮开始前干净；现有两个 Task MD 将保留历史并迁移，不丢记录。
- 已将目录迁移为扁平的 `active/` 与 `archive/`，删除固定线、阶段、优先级、轨道、标签管理和网页写 API；现有任务改用自由 `stream`。
- README 已改为第一性原理与最小架构说明，明确 Agent 可创建任意数量、任意命名或带斜杠层级的 stream，也可完全不分流。
- 两次 PowerShell 临时清理命令被安全策略在执行前拒绝；随后改用经过路径断言的 Node 临时目录和精确空目录清理，没有遗留烟测数据。
- 已通过两个迁移任务的协议检查、全部 Node 语法检查、浏览器内联脚本语法检查、自由 stream 的 todo→review→reject→review→done 生命周期，以及真实 HTTP 首页/API 冒烟。

## 结果

已还原为自由 stream 的最小 Markdown 协议：净删约 1600 行固定线与网页写逻辑；迁移、三态生命周期、语法、协议检查和 HTTP 冒烟均通过
